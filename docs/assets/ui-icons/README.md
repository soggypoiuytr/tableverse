# Ícones da interface Aurality

Gerados com a ferramenta integrada de geração de imagens. O atlas original está em `aurality-tool-atlas.png`; os 16 recortes PNG mantêm a transparência.

Prompt utilizado:

Create ONE production UI sprite atlas image, square 1024x1024, transparent alpha background. Exactly 4 columns by 4 rows, 16 equal 256x256 cells. Each cell contains ONE isolated small sci-fi HUD tool icon, centered at the exact cell center, icon fits within 140x140 pixels with empty transparent padding. Consistent premium minimal futuristic military neural interface aesthetic: crisp pale cyan-white metal strokes, very subtle muted crimson accent at one corner of each icon, no background plaques, no tile borders, no labels, no text, no numbers, no shadows outside silhouette, no decorative noise. Thin but legible 8px luminous beveled strokes on transparency. The icons must be clearly distinguishable at 20px display size, elegant simple shapes, not complex illustrations. Exact row-major content: ROW1: mouse arrow pointer, diagonal measuring ruler, location pin with target ring, document sheet with lines. ROW2: icosahedral twenty sided dice outline without numbers, square 3x3 grid, sun illumination lamp, gear settings. ROW3: folded map, speech chat bubble, archive box, initiative ordered horizontal list. ROW4: notebook, left return arrow, eye visibility, send paper airplane. Keep all objects rigorously within their own cell with transparent gap, no visual bridges between icons. This is one cohesive icon atlas for an existing dark navy/red/cyan tabletop RPG interface called Aurality; do not write that name.
